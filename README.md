# Sebastián Macías

Desarrollo herramientas locales para trabajar con gráficos vectoriales en procesos de producción.

## Proyectos

### [SkNesting](https://github.com/Tomoya0k/SkNesting)

Motor local para acomodar piezas de archivos SVG y EPS en hojas rectangulares. Considera giros, separación entre piezas, concavidades y agujeros; muestra el resultado hoja por hoja.

### [SkLed](https://github.com/Tomoya0k/SkLed)

Herramienta local para revisar contornos SVG y preparar recorridos LED. Separa figuras y subtrazados, permite inspeccionar las capas del diseño y ajustar medidas de módulos.
